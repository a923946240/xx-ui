# 上报公网 IPv4 并同步出站

以台湾上报、香港接收、前置同步为例，三台面板都需要支持「NAT 地址池」。

1. **台湾**在「节点」中添加香港，使用通过证书校验的 HTTPS 和节点同步令牌或 mTLS。打开「NAT 地址池 → IP 上报」，选择香港，填写方便辨认的名称（例如「台湾 NAT」），点「开始上报」。收到首次回执后，台湾每 30 秒主动向香港上报一次。
2. **香港**打开「节点 → NAT 地址池」查看最新 IP 和上报时间。香港从台湾直连 HTTPS 的 TCP 来源取得公网 IPv4。使用 API 令牌时，请为每个上报面板使用不同的令牌。地址池只列出过去两分钟内收到的记录。
3. **前置**只需把香港添加为通过证书校验的 HTTPS 节点。在「组网 → 出站 → NAT 同步向导」选择香港的地址池，再选「台湾 NAT」和出站，点「检测并启用」。从出站行的菜单打开向导会自动选中该出站。

前置会沿用出站现有端口和拨号链测试上报地址，拨通才更新。上报过期或拨号失败时继续使用当前地址。台湾和香港之间需要直连公网 IPv4 HTTPS，改变来源地址的反向代理会让接收端无法观测到台湾的实际出口。

此前已启用的节点拉取配置按原有方式继续运行。在新向导中可以停止旧任务，重新设置时选择地址池。使用节点同步令牌的上报端，轮换令牌时沿用原有名称，以保持原地址池条目的身份。若另有旧版 SSH 定时脚本，停用后再开启面板自动同步。[旧脚本停用说明](https://github.com/a923946240/xx-ui/blob/v3.15.0/scripts/nat-outbound-sync.md)
