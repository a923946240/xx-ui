# 上报公网 IPv4 并同步出站

使用 NAT 地址池需要三台面板都支持该功能（v3.17.0 起）。在 Web UI 中先配置上报，再到前置查看地址。

## 先配置上报

1. 在**上报面板**的「节点」里添加**接收面板**，使用通过证书校验的 HTTPS 和节点同步令牌或 mTLS。已有连接可直接选用。使用 API 令牌时，每台上报面板用自己的令牌。
2. 在上报面板打开「节点 → NAT 地址池 → IP 上报」，选择刚添加的接收节点，填写要在池中显示的名称，然后点「开始上报」。首次上报成功后，面板每 30 秒主动上报一次。
3. 在**接收面板**打开「节点 → NAT 地址池」，切到「NAT 地址池」标签页，核对上报名称、IP 和时间。接收面板从直连 HTTPS 请求的来源取得公网 IPv4，地址池显示过去两分钟内收到的记录。

## 在前置查看上报 IP

1. 在**前置面板**的「节点」里添加同一个**接收面板**。连接使用通过证书校验的 HTTPS，认证使用节点同步令牌或 mTLS。已有接收节点可直接选用。
2. 打开「组网 → 出站 → NAT 同步向导」，在「地址池所在节点」选刚添加的接收节点。
3. 展开「上报地址」。每个选项会显示上报名称和公网 IPv4。**只查看 IP，展开下拉框即可。**

如果列表为空，先点「刷新状态」，然后到接收面板核对上报时间。上报面板需要通过公网 IPv4 和 HTTPS 直连接收面板，接收端才能看到实际的出口 IP。

## 启用自动同步

在前置选中上报地址和要同步的出站，再点「检测并启用」。从出站行的操作菜单打开向导，会自动选中该出站。前置使用原端口和拨号链测试上报地址，拨通才更新。上报过期或拨号失败时，继续使用当前地址。

使用节点同步令牌的上报面板，轮换令牌时沿用原名称，以保留地址池条目的身份。此前已启用的节点拉取任务，可在新向导中停止并切换到地址池。另有旧版 SSH 定时任务时，先[停用旧脚本](https://github.com/a923946240/xx-ui/blob/v3.15.0/scripts/nat-outbound-sync.md)，再启用面板自动同步。
