# 节点 NAT 出站地址同步

在主控的「节点 → 添加节点」登记接收节点和上报节点。两台机器都需要运行支持 NAT 同步接口的 xx-ui，并能通过已验证的 HTTPS 从主控访问。节点认证可以使用具备节点同步权限的 API 令牌或节点 mTLS。

1. 打开主控的「组网 → 出站 → NAT 同步」。
2. 选择接收节点、上报节点，以及使用同一个 NAT 公网 IPv4 的出站。目标出站应已保存并使用拨号代理，出站测试 URL 应为 HTTPS。
3. 点「测试连接」并核对返回的 IP。接收节点需要允许上报节点从目标公网 IPv4 直接连接它的面板 HTTPS 地址。会替换连接来源的反向代理不能用来观测 NAT 地址。
4. IP 正确后启用并保存。主控定期向接收节点请求一次性凭据，再让上报节点直接发出 HTTPS 请求。接收节点记录连接来源，主控先通过原有拨号链探测，再更新所选出站地址。

节点同步无需 SSH 密钥、服务器命令或额外的定时任务。旧版面板的 SSH 同步设置不会自动启用节点版同步。若已在服务器上另行部署旧脚本，启用新方式之前先停止旧定时任务，避免两边同时更新同一条出站。[旧版部署与停用说明](https://github.com/a923946240/xx-ui/blob/v3.15.0/scripts/nat-outbound-sync.md)
